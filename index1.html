ℹ️ Cómo funciona «Unirse»

El botón intenta abrir Roblox con el identificador del servidor elegido. iPhone o Roblox pueden impedir el acceso directo a una instancia específica; si sucede, abre el juego normalmente. No garantizamos que el servidor tenga huevos raros.

La consulta usa la API pública de servidores de Roblox. Si Safari bloquea el acceso entre dominios (CORS), será necesario configurar un intermediario autorizado; esta página no puede eliminar esa restricción.
